# First Login

After installation and seeding, navigate to `https://orbital.test` (or your configured domain).

## Admin Panel

Access at `/admin`. Available to users with the `super_admin` role. This is where you configure clients, manage platform infrastructure, and monitor system health.

## Operator Panel

Access at `/operator`. Available to users with any platform role (operator, supervisor, super_admin). This is the day-to-day workspace for handling calls and email.

When you first log in as an operator, your availability is set to **Unavailable**. Switch to **Available** using the selector in the top bar to start receiving work.

## Customer Portal

Access at `/portal`. Available to client contacts — the customers whose calls and messages you handle. They can view messages, call history, and recordings.
