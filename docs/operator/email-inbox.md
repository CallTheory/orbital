# Email Inbox

The email inbox shows threads assigned to you plus unclaimed threads in queues you're a member of. Navigate to **Operator > Inbox > Email Inbox**.

## Availability

Your availability status (shown in the top bar) affects what you see:

- **Available**: Full thread list with all data visible. You can claim, reply, forward, and close threads.
- **Unavailable**: Thread rows show shimmer placeholders. The badge count is still visible so you know work is waiting.

Switch to Available when you're ready to start working.

## Thread List

The inbox table shows:

| Column | Description |
|--------|-------------|
| **Received** | When the last message arrived (in your timezone) |
| **Subject** | Thread subject — click to open the thread |
| **Client** | Which customer this thread belongs to, with the delivered-to address below |
| **Status** | New, In Progress, Awaiting Reply, or Closed |
| **Queue** | Which email queue the thread is in |
| **Claimed by** | Click the green "Claim" badge to take ownership, or click your name to unclaim |

## Viewing a Thread

Click the received date or subject to open a thread. Messages are shown as collapsible sections — the most recent message is expanded, older messages are collapsed. Click any collapsed message to expand it.

Each message shows:
- Sender name and address
- Timestamp in your timezone (and client timezone if different)
- Direction indicator: "received" for inbound, "sent" for outbound
- Subject, recipients, body text, and attachments

## Actions

Actions are available in the thread view header:

| Action | Description |
|--------|-------------|
| **Reply** | Send a threaded reply to the original sender |
| **Forward** | Forward the latest message to any email address with an optional note |
| **Unclaim** | Release the thread back to the unclaimed pool |
| **Close Thread** | Mark as handled — drops out of the default inbox view |
| **Reopen Thread** | Move a closed thread back to active status |

## Activity History

Every action on a thread is logged in the Activity table at the bottom of the thread view. This shows who did what and when — claims, replies, forwards, closes, and reopens.

## Filtering

Use the "Include closed" filter to toggle visibility of closed threads. By default, only open threads are shown.

The search bar searches across subject lines, message bodies, and sender addresses.
